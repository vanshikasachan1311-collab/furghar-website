# FurGhar Image Assets

Save website images in this folder using these recommended names:

- `logo.svg` - FurGhar logo for navbar and footer
- `hero-pets.webp` - hero section dog/cat/cozy home image
- `story-kaju.webp` - Our Story section image inspired by Kaju
- `why-home.webp` - optional visual for home-like environment
- `host-family.webp` - Become a Host section image
- `parent-care.webp` - Find a Host / pet care request section image
- `instagram-preview.webp` - Instagram journey preview card

Recommended formats:

- Use `.svg` for logos and illustrations.
- Use `.webp` for photos.
- Keep hero images around 1600px wide or smaller for performance.
- Add meaningful alt text when importing images into Vue components.
